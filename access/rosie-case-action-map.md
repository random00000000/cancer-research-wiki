# Rosie Case Action Map For Humans

Status: first-pass action map
Last updated: 2026-06-14

Audience label: public education, advanced-options navigation, clinician discussion support, research support, not medical advice.

## Summary

The useful lesson from the Paul Conyngham/Rosie story is not "ChatGPT cured cancer." The useful lesson is that a determined person assembled facts, tumor data, AI-assisted research, sequencing expertise, RNA expertise, immunotherapy expertise, ethics/oversight, supervised treatment, and response tracking.

For humans, that must become an expert-led workflow. The output is not a recipe. The output is a case package and outreach system that lets qualified cancer teams evaluate advanced options quickly.

## Human Version Of The Workflow

1. Freeze the current facts: diagnosis, stage, pathology, imaging, prior treatment, response, progression, and current clinical risks.
2. Build a records packet that an outside expert can review in one pass.
3. Identify missing decision-grade data: biomarkers, tumor sequencing, germline testing, HLA, RNA expression, fresh tissue, ctDNA, or repeat biopsy.
4. Use AI to map questions, papers, trials, biomarkers, and expert contacts, with citations and uncertainty labels.
5. Ask the treating oncologist for molecular tumor board review or referral to a center that can do it.
6. Search legitimate trials by cancer type, stage, biomarkers, prior treatment, and location.
7. If no trial fits, ask about expanded access, compassionate use, off-label evidence review, or named-patient access only through a licensed clinician and appropriate oversight.
8. If mRNA/neoantigen therapy is relevant, ask about legitimate trials, tissue requirements, sequencing, HLA, manufacturing time, combination therapy, endpoints, and toxicities.
9. Track what happens: treatment dates, scans, labs, symptoms, adverse events, response, progression, and new mutations if retested.
10. If the cancer adapts, update the packet and repeat expert review rather than improvising a protocol.

## What This Is Not

- Not DIY vaccine design.
- Not self-dosing.
- Not procurement guidance.
- Not proof that AI can cure cancer.
- Not permission to skip standard oncology care.
- Not a promise that a poor person can access the same infrastructure as a one-off veterinary experiment.
